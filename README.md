The video phase1_ ui.mp4 showcases the foundational user interface for the Movies App project. It demonstrates a smooth and professional flow that aligns with modern Flutter development standards.

UI Flow Breakdown
Splash & Onboarding: The app opens with a cinematic splash screen featuring the "Route" logo, followed by an onboarding sequence that introduces core features: discovering movies, creating watchlists, and instant streaming.

Authentication: The Login screen includes the custom "OR" divider we optimized, email/password fields, and a "Forget Password" option. It also features the language toggle (English/Arabic) at the bottom.

Account Creation: The Register screen allows users to select an "Avatar" for their profile, which adds a personalized touch to the onboarding process.

Profile Management: The Profile tab displays user statistics (Wishlist count and History) and provides options to edit profile data, reset passwords, or delete the account.
